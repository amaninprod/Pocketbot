## 📖 Overview

**Pocketbot** is a chatbot application front-end. It provides a conversational interface for users to interact with a bot, demonstrating chat UI design and front-end interaction patterns.

> 🎯 **Purpose:** Chatbot UI demonstration project

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 💬 **Chat Interface** | Conversational UI design |
| 🤖 **Bot Responses** | Simulated bot responses |
| 📱 **Responsive** | Works on mobile and desktop |
| 🎨 **Modern UI** | Clean chat interface |
| ⚡ **Fast** | Lightweight front-end only |

---

## 🛠️ Tech Stack

| Layer | Technologies |
|-------|-------------|
| **Frontend** | HTML5 · CSS3 · JavaScript |
